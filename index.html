📲 Install App & Add Shortcuts

Universal Offline PWA: You can use this platform 100% offline on any Windows desktop or install it as an app icon on Android and iPhone!

📱 Mobile (Android & iPhone):

Visit the live secure link on your smartphone browser:

https://atuldhuvad-cmd.github.io/Universal-Training-PWA/
  • Android (Chrome): Tap the three dots (⋮) in the top-right → Tap "Install app" or "Add to Home screen".
  • iPhone / iPad (Safari): Tap the Share button (square with arrow) → Scroll down & tap "Add to Home Screen".

💻 Windows Desktop:

  • Desktop Shortcut: Run Create_Desktop_Shortcut.bat inside the app folder to instantly place a shortcut on your Windows desktop with the official icon.
  • Standalone App Mode: Double-click Launch_PWA.bat to run the app as a dedicated, distraction-free desktop window without browser tabs or address bar.
  • Browser Install: When opened in Chrome or Edge, click the Install (computer) icon in the URL omnibox to add it to your Windows Start Menu and Taskbar.
